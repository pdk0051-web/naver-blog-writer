      글을 써 줄 AI를 하나 골라 주세요. 처음이라면 Google Gemini(무료로 시작)를 추천해요.

      네이버 계정

      아직 로그인 정보를 확인하지 못했어요.

      이렇게 써요

      1. 왼쪽 화면에서 내 네이버 계정으로 직접 로그인해요. 한 번 로그인하면 다음에도 유지돼요.
      2. «AI 연결» 탭에서 쓸 AI를 골라요.
      3. 주제와 내 메모를 적고 «글 만들기»를 눌러요.
      4. 미리보기에서 제목과 본문을 다듬고 «편집기에 넣기»를 눌러요.
      5. 왼쪽 편집기에서 사진을 직접 넣고 내용을 확인해요.
      6. «임시저장»을 누른 뒤, 발행은 네이버 화면에서 직접 해요.

      꼭 알아 두세요

      • 이 앱은 네이버와 관계없는 비공식 도구예요.
      • 자동 글 등록은 네이버 이용약관과 맞지 않을 수 있어서, 이 앱은 임시저장까지만 하고 발행은 사람이 직접 해요.
      • AI가 쓴 글은 사실과 다를 수 있어요. 발행 전에 꼭 읽고 고쳐 주세요. 글의 책임은 글쓴이에게 있어요.
      • 광고·협찬을 받은 글이라면 공정거래위원회 지침에 따라 글에 분명히 밝혀 주세요. 필요하면 AI 도움을 받았다는 점도 알려 주세요.
      • API 키와 메모는 이 컴퓨터에만 저장돼요. 이 앱은 따로 서버나 통계 수집을 쓰지 않아요.
